## 📖 Project Overview

This is a job application tracking tool where users can add, manage, and monitor their job applications with status updates. The project was built as part of my **Programming Hero Batch 13** assignment to practice DOM manipulation and localStorage in JavaScript.

---

## ✨ Features

- ➕ Add new job applications easily
- 📊 Track application status (Applied, Interview, Rejected, Hired)
- 🗑️ Delete applications
- 💾 Data saved in localStorage (no data lost on refresh)
- 📱 Fully responsive design

## 💻 Run Locally

Follow these steps to run the project on your local machine:

### ১. Repository Clone করো

```bash
git clone https://github.com/Mohammadsajibulislam/My-Assignment-4.git
```

### ২. Project folder-এ যাও

```bash
cd My-Assignment-4
```

### ৩. index.html ফাইলটা browser-এ open করো

```
index.html ফাইলে double click করো
অথবা VS Code-এ Live Server দিয়ে open করো
```

> ⚠️ কোনো `npm install` বা server লাগবে না — সরাসরি browser-এই চলবে!
